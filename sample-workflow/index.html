Illustrative example. This is a reusable planning template, not a customer case study. It has not been installed in your tools. Review it against your process before using it.

1. Define the finish line

Every normal quote request has a recorded owner and next action. The office can see what is waiting without searching through forwarded emails.

2. Keep one record

Field What belongs here
Request ID The original message link or another unique reference
Contact and request Name, business contact method, service location, and a brief description
Owner The person responsible for the next action
Status Needs review, waiting for details, assigned, or closed
Next action A concrete step and a time chosen by the responsible person
Outcome Quoted, booked, declined, duplicate, or unknown

3. Agree the routing rules

  1. New request: the office checks service area and completeness.
  2. Missing details: the office asks for the specific missing information.
  3. Ready to quote: assign one estimator and record the next action.
  4. Duplicate or existing job: attach it to the existing record.
  5. Unclear, sensitive, or urgent: route to a person. Keep the existing emergency contact process; email triage is not emergency dispatch.

4. Start with three templates

Acknowledgement

Thanks for your request about [service]. Our office will review the details and confirm the next step. This message does not confirm an appointment or a price.

Missing information

To route this to the right person, could you send [specific missing detail]? Once we have that, we can confirm the next step.

One optional follow-up

Would you still like help with [request]? If so, send [specific next detail]. If your plans have changed, no further action is needed.

Use a template only when it accurately matches the conversation. Stop follow-ups after a reply, opt-out, completed request, or failed delivery.

5. Set up the simplest version first

  1. Create a shared list with the fields above. Limit access to the people handling requests.
  2. Agree who checks new requests and who covers absence during working hours.
  3. Save the reviewed templates in your existing email tool.
  4. Walk through the tests below manually.
  5. Only then consider an integration to copy details or prepare drafts. Retain a review queue for uncertainty and a record of each action.

6. Test before connecting live work

  • A complete request reaches the correct owner.
  • A request without a location gets a request for that detail.
  • Reprocessing the same message does not create a second record or reply.
  • A reply, opt-out, or bounce prevents further nudges.
  • An unavailable tool leaves the original request visible for review.
  • An urgent message follows the existing human contact process.

7. Measure whether it helps

For one normal working week, record requests received, requests without an owner, time to a useful first reply, minutes spent handling requests, and known outcomes. Compare a similar week after the change. Keep unknown outcomes separate and do not attribute extra sales to the workflow without evidence.
