# Kavikworks Site Agent Instructions

Before doing substantive work in this repository, read this file and the
[canonical operating architecture](docs/operating-architecture.md).

- Treat GitHub as the technical source of truth.
- Check **Kavikworks HQ** in Notion for operational context, current tasks,
  projects, decisions, prospects, experiments, and handoffs.
- Use Google Drive for relevant durable business artifacts and link those
  artifacts from the corresponding Notion records.
- Treat the local Obsidian wiki as cache/context only, not as cross-agent
  operational authority.
- Never treat ChatGPT conversation history, a browser session, or local
  uncommitted state as authoritative project state. Externalize material results
  before ending the session.
- Keep secrets, credentials, tokens, and sensitive customer data out of this
  public repository and out of session notes. Keep private operational links
  out of this public repository; store necessary GitHub and Drive references in
  the access-controlled Notion records that require them.

Follow the session start, during-session, session-end, handoff, and change
control protocols in the canonical document. Keep this file concise; update the
canonical document for architecture changes and change this bootstrap file only
when its instructions or link need to change.
